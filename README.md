# ovice-emoji-assets

oVice絵文字ピッカー拡張の同梱画像アセット置き場です。

拡張をインストールすると、ここに置いた画像がセットごとのタブに入った状態で使えるようになります。
画像はユーザースクリプト本体には埋め込まず、[jsDelivr](https://www.jsdelivr.com/) のCDN経由で配信しています。

- ユーザースクリプト本体: https://gist.github.com/blogmonomono/fe25ca76959d79cd7f0e00ab0400465e

## セット一覧

| フォルダ | 枚数 | 内容 |
| --- | --- | --- |
| `kiiro/` | 120 | 黄色いまるっとした絵文字 |
| `kuma/` | 130 | くまの絵文字 |
| `usagi/` | 130 | うさぎの絵文字 |

## 配信URL

タグを打った時点の内容が、次の形のURLで読めます。

```
https://cdn.jsdelivr.net/gh/blogmonomono/ovice-emoji-assets@v2/kiiro/emoji_001.png
```

`@v1` のようにタグで固定するとjsDelivr側にずっとキャッシュされるため、表示が速く、
あとから中身が変わって崩れる心配もありません。`@main` を指すと数時間ぶんのキャッシュ待ちが
発生するので、配布用のURLでは必ずタグを使ってください。

## セットを追加するとき

1. 新しいフォルダを作って画像を入れる（ファイル名は半角英数の連番が無難です）
2. commit して push する
3. 新しいタグを打つ

   ```sh
   git tag v2 && git push origin v2
   ```

4. ユーザースクリプト側の `DEFAULT_IMAGE_BASE` を新しいタグに差し替え、
   `DEFAULT_IMAGE_SETS` にセットを1件足す

既に拡張を使っている人にも、次回起動時に増えたセットのぶんだけタブが増えます
（配布済みのセットは記録してあるので、消したセットが復活することはありません）。

## 画像について

oViceのフキダシでの表示は最大 170x65px 程度です。それより大きい画像を置いても
表示は変わらないため、100px前後まで縮めておくと通信量を抑えられます。
ただしGIFアニメは縮小の仕方によっては1コマ目で止まってしまうので、無加工のまま置いてください。
